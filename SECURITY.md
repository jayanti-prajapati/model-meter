# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature if enabled, or contact the maintainers privately using the security contact configured for the repository.

## Scope priorities

- Cross-tenant data exposure.
- Authentication and authorization bypass.
- Ingestion key compromise.
- Provider credential exposure.
- SQL injection or unsafe query construction.
- Cost manipulation or duplicate ingestion that materially corrupts customer reports.
- Unsafe import processing or sensitive-data leakage.

## Supported versions

The project is at the planning/scaffold stage. Supported release versions will be documented once releases begin.
